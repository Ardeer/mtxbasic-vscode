<comment> = 0x08 
<offset from start of code block> = 0x00 0x00 
<length of comment> = 0x11 
<comment> = 0x54 0x65 0x73 0x74 0x81 0x6F 0x66 0x81 0x63 0x6F 0x6D 0x6D 0x65 0x6E 0x74 0x73 (Test of comments)
(NOTE: if a space is present then bit 7 is set and for every consecutive space add 1, so 1 space = 0x81 and 4 spaces would be 0x84)
<end of comment> = 0xFF 

<end of code block> = 0xFF
