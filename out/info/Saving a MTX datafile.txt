Saving a MTX datafile in VS code

Persistence: output is a local array created inside convertTextToHex() and returned by it. It is not kept across sessions unless some code stores it somewhere (file, global state, or extension context). You must call convertTextToHex() each time you want to (re)generate the array.

Restarting VS Code: Pressing Developer: Reload Window / restarting the extension host will not automatically run convertTextToHex() or write any file — it only reloads the extension. You only need to restart if you changed extension code and want those changes loaded.

How to save the generated output to a file (quick, runnable method):

Create a small Node script (e.g. scripts/gen.js) in the extension root:

// scripts/gen.js
const fs = require('fs');
const { convertTextToHex } = require('../out/extension.js'); // adjust path if needed

const inPath = process.argv[2];
const outPath = process.argv[3] || 'output.bin';
if (!inPath) { console.error('Usage: node scripts/gen.js <input.bas> [out.bin]'); process.exit(1); }

const src = fs.readFileSync(inPath, 'utf8');
const bytes = convertTextToHex(src);          // number[] returned
const buf = Buffer.from(bytes);               // binary buffer
fs.writeFileSync(outPath, buf);
console.log(`Wrote ${bytes.length} bytes to ${outPath}`);

Run it in the workspace terminal:

node scripts/gen.js path/to/yourSource.bas panelcod.bin

This writes the raw bytes as a binary file. If you prefer a human-readable hex/text file, replace Buffer.from(bytes) with Buffer.from(bytes.join(',')+'\n','utf8') or similar.

                const editor = vscode.window.activeTextEditor;
